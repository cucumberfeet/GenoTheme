# Bundled fonts

Installed by `install.sh` into `~/.local/share/fonts/genotheme/` and selected
by `./install.sh --apply`. The files are unmodified.

| Family | Use | Licence |
|---|---|---|
| Rajdhani (Indian Type Foundry, 2014) | UI, menus, toolbars | SIL Open Font License 1.1 (`Rajdhani/OFL.txt`) |
| Orbitron (The Orbitron Project Authors, 2018) | Window titles | SIL Open Font License 1.1 (`Orbitron/OFL.txt`). Reserved Font Name "Orbitron". |
| Hack (Source Foundry, 2018; based on Bitstream Vera and DejaVu) | Monospace | MIT, plus the Bitstream Vera licence (`Hack/LICENSE.md`). Not OFL, but redistribution with the theme is allowed. |

`./install.sh --apply` sets Rajdhani Medium 10, Orbitron 8 for window titles
and Hack 10 for monospace, matching Balthasar.

# Vendored panel plasmoids

These are the six third-party Plasma 6 applets used by the Balthasar panel
layout. They are installed into `~/.local/share/plasma/plasmoids/` by
`install.sh` (no root). Each one keeps its own licence.

| Id | Name | Author | Licence |
|---|---|---|---|
| `org.kde.netspeedWidget` | Netspeed Widget | Daniel Faust | GPL-2.0-or-later |
| `org.kde.olib.thermalmonitor` | Thermal Monitor | Oliver Beard | MIT |
| `org.kde.mediabar` | MediaBar | Panagiotis Panagiotopoulos | GPL-3.0-or-later |
| `zayron.simple.separator` | simple separator | zayronxio | GPL-3.0-or-later |
| `com.himdek.kde.plasma.overview` | Overview | Himprakash Deka | GPL-3.0-or-later |
| `net.prime42.plasma.dotdesktopindicator` | Dot Desktop Indicator | Prime42 | GPL-3.0-or-later |

Upstream screenshot images were not included. The applet source, translations
and licence notices are.
